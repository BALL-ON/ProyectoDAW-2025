# Nombre de Vuestro Proyecto

## Tecnologías
* **Backend:** Java (Spring Boot)
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
* **Base de datos:** MySQL

## Instalación y Puesta en Marcha

### 1. Clonar el repositorio
git clone [URL_DEL_REPO]

### 2. Base de Datos
Crea una base de datos en MySQL llamada `nombre_proyecto_db`.

### 3. Backend
1.  Entra en la carpeta `/backend`.
2.  Abre el proyecto en IntelliJ/Eclipse.
3.  Edita `application.properties` con tu usuario/pass de MySQL.
4.  Ejecuta la clase principal. El servidor iniciará en `localhost:8080`.

### 4. Frontend
1.  Entra en la carpeta `/frontend`.
2.  Abre el archivo `index.html` en tu navegador.
